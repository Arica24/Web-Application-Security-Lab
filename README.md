# Web Application Security Lab

A university lab assessment of OWASP Juice Shop using Burp Suite, browser tools and manual HTTP testing.

## What this shows

- Inspecting and modifying HTTP requests.
- Investigating authentication, role and object access controls.
- Checking input handling and business rules.
- Assessing evidence, limitations and appropriate remediation.
- Writing a security assessment.

## Report

[Read the portfolio report](Web_Application_Security_Assessment.pdf).

This portfolio edition critically reviews eight areas from the original December 2025 coursework. It separates reported observations from unverified hypotheses and corrects technical explanations. The original lab has not been rerun; this is not a new penetration test. Historical DREAD totals are retained without unsupported severity labels.

Student details, original request screenshots, credentials and session tokens are excluded. This text-only version can be extended with sanitised evidence after review.

## Scope and attribution

Testing described in the report was performed against a local, deliberately vulnerable educational application. Only test systems you own or have permission to assess.

Original assessment: Arica Bhuiyan. Training application and challenges: OWASP Juice Shop. This repository contains an assessment, not a web application built by the author.
